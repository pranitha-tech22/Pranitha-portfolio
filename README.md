# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, achievements, and resume. This portfolio serves as my digital presence, highlighting my journey as a Computer Science Engineering student and aspiring software developer.

## 🌐 Live Demo
https://pranitha-tech22.github.io/Pranitha-portfolio/

## 🌟 Features

- Responsive design for desktop and mobile devices
- Clean and modern user interface
- About Me section
- Skills showcase
- Projects section with project details
- Resume download option
- Contact section with social links
- Smooth navigation between sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Sections Included

### Home
A brief introduction and welcome section.

### About Me
Information about my educational background, interests, and career goals.

### Skills
A showcase of technical skills and technologies.

### Projects
A collection of projects demonstrating my development experience and problem-solving abilities.

### Resume
A downloadable version of my resume.

### Contact
Ways to connect with me through email and professional platforms.
